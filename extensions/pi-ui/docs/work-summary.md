# Compact 工作汇总

工作组是思考、过程说明与会话工具调用的展示单位；工作活动是直到宿主确认不再
自动继续的一次连续运行。一次模型回复结束、最终文字开始出现或重试等待都不
独立证明工作活动已经收尾。两者遵从根领域词汇表，不合并成一个计时概念。

活动时钟独立于当前展示挂载和样式模式。关闭样式期间的用户等待仍扣除，
settled 仍冻结时钟；切回 compact 不恢复已经结束的活动。重复的 `agent_start`
属于尚未 settled 的自动继续时，不重置活动时钟。

## 布局

compact 折叠时保留文件工具的独立卡，隐藏组内 eligible 会话工具调用和 Thinking。
折叠工作组只有一个中性汇总；持续变化的汇总位于当前组的末端，
不在长文件/diff 正文之前刷新历史 anchor。汇总始终单行并按终端显示宽度截断；
工具名称中的终端控制与换行不成为布局或输入控制。工作结束后同一展示变成静态汇总；
最终答复保持独立原生展示，工具结果和会话记录不被移动或改写。
尚未 settled 的纯文字也保持原生展示；其所属组与时钟不因文字开始流入而丢失。

工作组展开在原会话位置恢复 Thinking 和 eligible 工具，不将它们搬到统一的
anchor 面板。同一消息内 Thinking、文字与工具卡也按记录的内容顺序交错，
进程文字不会整体提前、工具卡也不会被推到最后；过程说明、write/edit/apply_patch
文件卡与其他专用卡保持自己的原生展示及相对顺序，因此说明和对应操作不会被
后续操作隔开；最终答复仍独立。
组的展开状态控制成员可见性，不强行合成连续的大背景框。过程内容可以分段显示，
展开背景使用 `expandedCardBackground`，工具仍可单独展开，键盘/鼠标入口保持可用。
尾部汇总不轮换 Thinking 或工具正文，不是单槽 live preview，没有自动收纳或
收尾静默期。

## 状态与所有权

活动开始、明确等待用户和最终 settled 由公开宿主事件驱动。重试和自动继续不
提前收尾。收尾区分正常结束与被中止的运行：被中止的活动报告取消而不是完成
时长，该结局随工作组保留，重绘结论稳定。工作耗时是覆盖工作时段的经过
时间，扣除明确用户等待，不是并行工具耗时之和。汇总是中性的过程记录，不判断
任务成功或汇总失败次数。

## 语义计数

每个工作组独立统计所有已捕获的会话工具调用，不以 renderer 是否 eligible 过滤。
每个非空 Thinking content 条目计一次；同一条目的流式增长或替换不增加次数，
未公开的内部推理不被推测。计数从当前记录重算，不以时间戳作为条目身份；
最新消息已移除的 Thinking 条目不从旧流片段补回。
同一消息开始流入文字后仍按其最新 Thinking 条目重算；保存的 Thinking 与文字混合
消息也恢复过程汇总，文字继续保留在其原会话位置的原生答复展示中。

- `Thought N times`：非空 Thinking 条目。
- `Read N files`：read 的已记录路径字符串去重，offset/limit 不改变对象身份。
- `Searched for N patterns`：grep 与 find 共用 pattern 字符串去重，不区分搜索目录。
- `Listed N directories`：ls 的已记录目录字符串去重。
- `Ran shell N times`：bash/PowerShell 调用次数，不解析命令内容。
- `Used <tool name> N times`：其他工具，或缺少必要对象参数的调用。

单数使用 `time`、`file`、`pattern`、`directory`。路径和目录不归一化、不按当前
cwd 解释，也不访问文件系统补全记录。文件/diff 和 dedicated/native 工具卡仍由
原 renderer 呈现；参与汇总不改变工具卡所有权。

公开 `tool_execution_*` 的 `parentToolCallId` 将内部操作关联到父调用所属工作组；
保存的工具结果 `nestedCalls` 用于最终记录和重放。内部调用按 id 去重，流式事件和
最终快照不重复累计；内部与顶层调用共享文件、pattern、目录对象去重。
迟到的观察仍更新父调用的组，不进入最新组，也不创建独立内部工具卡。
缺少内部 arguments 时保守回退为调用次数；最终 `complete: false` 只统计已知
部分并附 `partial records`，不等同于执行失败或输出截断。导航、reload 和反复
挂载从当前会话的保存记录恢复，不再次执行工具或累计相同观察。保存 projection
替换旧的内部快照；已不在当前记录中的调用和 partial 标记不残留。尚无最终结果的
当前父调用保留已公开的 live 观察，样式切换不丢失其已知操作。

用户消息或可见的独立通知划分工作组，不自行结束仍在运行的工作活动。
消息时间戳不是工作组或消息的唯一身份。
已知的工作组成员关系独立于挂载，展示刷新不会合并通知或用户消息边界两侧的
工作组；重放也尊重原消息顺序中的分界。多 assistant 成员的展开工作组只由
anchor 拥有外层展开状态，展开子工具不会收起外层或丢失其他成员内容。

展示挂载受现有无副作用能力预检、补丁品牌、会话 generation 和 identity 清理
约束。导航、compaction、reload 和模式切换重新核对挂载容器；旧展示不会更新
新会话，释放顺序保持逆序。已有历史只读恢复，不按当前时间发明历史耗时。

## regular 与 fullscreen

两种终端模式使用同一汇总身份和活动生命周期。regular 让终端拥有滚动历史，
不修改宿主清屏算法、光标、滚轮或回到底部行为。稳定终端尺寸与正文下，汇总
及其扫光的周期更新不得触发 scrollback 清空；其他宿主消息/工具历史重绘仍由
其原有所有者负责。没有离屏可见性探测、视口停帧或伪造前一帧机制。

验证从实际宿主加载的展示、生命周期和终端写入观察行为。导航/重载后的身份、
长文件卡下的持续时钟、正常结束、取消、重试和用户等待共同构成验收；目标终端
视觉与输入验收另按模块 acceptance 文档执行。
