# 上游展示改动的吸收取舍

本文件记录 `pi-ui` 的产品范围与上游评审规则，不是版本更新日志，也不表示某项
改动已经实现。实际保留的源码来源仍由
[第三方通知](../licenses/claude-style-tools-THIRD_PARTY_NOTICES.md)记录。
后续分析 `pi-cc-extensions` 更新时，先按这里的范围筛选，再核对本地行为。

## 不引入的功能

- 本地币种与费用换算：保持现有美元费用展示，不引入 `footerCurrency`、
  `footerCurrencyRate` 或预制汇率。
- 输出速率与首 token 延迟：不引入平均/实时 tok/s、TTFT 或对应采集与配置。
- edit summary-only：不引入零行 edit 预览选项，保持现有文件/diff 卡。

这些是不吸收的功能，不是等待上游修复后自动补齐的缺口。

## Compact 工作汇总

保留本地已有 compact 模式，以语义化工作汇总作为吸收展示改进的方向：
描述思考与工具操作，而不是仅列出 `bash×3, read×12` 等工具名与次数。
目标表述包括 `Thought 3 times`、`Searched for 1 pattern`、
`Read 12 files`、`Listed 1 directory`。文件路径、搜索 pattern 和目录按对象
去重；同一文件不同读取区间不增加文件数，同一 pattern 在不同目录搜索不增加
pattern 数；grep 与 find 合并为同一个搜索类别，跨两种工具按 pattern 字符串
去重。计数范围是当前工作组，不跨工作组或整个工作活动累计。
路径按记录中的原始字符串去重，不以当前 cwd 或磁盘状态合并历史路径。
`Thought` 计入已捕获的非空 Thinking 条目，同一条目的流式增量不重复计数，
不推测未公开的内部思考。

Shell 用 `Ran shell N times`，其他工具用 `Used <工具名> N times`。
缺少对象参数时回退到调用次数，不编造文件、pattern 或目录数；不能从 shell
命令文本猜测文件读取或搜索操作。

保持本地尾端单行布局，宽度不足时省略，不将动态汇总搬到工作组顶部或自动换行。

工作汇总与相邻工具卡的工具组头不是同一展示。上游工具组头的计数调整不能
直接替代工作汇总的语义化。汇总仍是中性过程概括，不借措辞判定任务成功。
纳入公开事件与已保存 `nestedCalls` 中的内部操作，按父调用归属工作组，
顶层与内部操作共用对象去重，实时事件与结果快照按调用身份去重。内部操作
仍属于父工具的过程，不因此生成独立工具卡；专用 renderer 仍保留原展示。
不能仅靠脚本或 shell 命令文本猜测操作种类或次数，也不改变会话保存格式。
参数省略时回退到已知调用次数；收尾后的内部记录仍不完整时只统计已知部分，
附 `partial records`，不将未记录操作计为零或宣称统计完整。

保留本地工作组、工作活动、尾端挂载和用户等待扣除等契约，见
[工作汇总](work-summary.md)；吸收上游 compact 改动不等于替换这些契约。

## Shell 耗时

允许吸收 shell 耗时展示，使用宿主记录的 `durationMs`，不新增 renderer 自行
计时。单卡已有耗时展示时不重复添加；工具组中的耗时可在相同口径下补充。
单次工具耗时与工作耗时分开，不能将并行工具耗时相加作为工作耗时。

## 置顶用户提示

纳入 fullscreen 置顶用户提示，默认开启并允许关闭。ccstyle 的 `on` 与
`compact` 模式中，用户消息正文首行滚出视口上沿后置顶该行；后续用户消息
滚出上沿后接替，点击置顶行跳回原消息。regular 与 `off` 模式不显示。

置顶行只拥有自身绘制范围内的鼠标命中，不消费滚动条列的点击或 hover。
帧合成与消息标记补丁须遵从本地能力预检、品牌与 identity 清理；没有标记消费方
时不能注入标记，也不能将标记写入终端或改变保存的消息内容。

## 修复与边界

- 修复重放时工作组跨用户消息合并，以及多成员工作组内展开工具误收起外层组。
  用户消息划分工作组，组内子项展开不改变外层工作组的展开状态。
- Thinking 的标题文字与明确的展开提示都可展开该 Thinking，保留外层工作组；
  正文拖选、链接及其他非操作内容仍不授予展开权限。
- 当前活动中的工具从已声明的等待窗口开始显示 pending 动画，直到真实结果
  接替状态；动画不宣称已经开始执行，历史残留调用不凭空启动动画。
- Fullscreen 鼠标展开工具或工作组时停住底部跟随，避免点击行随内容长高跳走；
  收起保持当前视口，不跳回展开前旧位置。regular 仍由终端管理滚动历史。
- 先检查本地是否存在同类可达问题，不以缺少上游函数或补丁名称判定缺失。
- 区分已覆盖的行为、真实缺陷、测试缺口与新的交互功能；不能将测试缺口写成
  已确认缺陷，也不能将新功能混入修复默认引入。
- 专用工具 renderer、宿主滚动与选择、补丁预检与所有权仍遵从本地架构。
  新增置顶提示或视口/滚动补丁等交互须独立确认，不随摘要改动自动吸收。
- 配置改名和上游迁移逻辑不作为同步目标；不因上游版本号变更而整版合并。
