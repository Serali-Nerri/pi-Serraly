# `/bg-clear`

Acknowledges unseen finished-task footer notices. It does not kill tasks, prune task history, delete logs, or remove metadata. Running counts remain visible. Opening one finished task's detail acknowledges only that task.

`Ctrl+Alt+C` is the terminal-dependent shortcut; `/bg-clear` remains the reliable fallback. See [dock controls](../reference/shortcuts-and-dock.md).
