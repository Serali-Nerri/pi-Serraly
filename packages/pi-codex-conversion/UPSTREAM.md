## Current local differences

- src/tools/ts-mode/portable-state.ts and worker.ts await local inspector validation of typed-array extra properties after synchronous graph capture, avoiding index-name allocations while preserving checkpoint identity and supported values. No inspector listener or persistent object handles are created. src/tools/code-mode/trace-values.ts stops payload traversal at either budget and clones bounded snapshots without consuming their payload budget again.
- src/providers/openai-codex/websocket-session-cache.ts and types.ts retire closed and superseded handshake routes without interrupting busy lanes or clearing canonical history. responses-lite.ts reuses normalized images in a bounded cache with cancellation-aware request-local processing; the native and configured proxy providers pass caller cancellation into preparation. Upstream request/retry policies and provenance pins are unchanged.
- src/tools/exec/session-manager.ts detaches completed replay tails from full-output string storage without changing immediate delivery or replay bounds. src/ui/tool-rendering/auxiliary-tool.ts captures only scalar render flags instead of retaining the host context and previous component chain.
- src/tools/exec/bridge-session.ts serializes reads per process; rust/main.rs lets native read waits complete concurrently while keeping mutations ordered, frames atomic and read-task cleanup explicit. scripts/build-native-tool-binary.mjs supports explicit targets; [Bundled native builds](./src/tools/native/README.md) owns that contract. Patch and exec helpers are rebuilt for all six bundled platforms, with unchanged upstream source pins.
- src/tools/apply-patch/executor.ts requests the summary response implemented by rust/standalone_executable.rs; detailed consumers remain supported. [Native patch response](./src/tools/apply-patch/README.md) owns the protocol and build contract. scripts/build-apply-patch-binary.mjs supports explicit targets and records both compiler host and artifact target; the vendored engine revision is unchanged.
- src/providers/openai-codex/transport/sse-request.ts, sse.ts, transport-recovery.ts, websocket-stream.ts and constants.ts align normal request timeouts with released Pi 1.5.2: no fixed 20-second header or five-minute stream-idle deadline. Explicit timeoutMs bounds SSE headers or WebSocket idle waits, not SSE body streaming. Header timers stop at response headers; caller cancellation, recovery/advice budgets, retries and WebSocket setup/prewarm deadlines remain unchanged. src/providers/openai-codex/AGENTS.md records this boundary; UPSTREAM_SYNC.md documents the comparison.
- src/adapter/code-mode/toolkit-updates.ts groups initial and Added/Changed tool announcements by explicit namespace, then by registering extension entry. Source labels use existing Pi metadata, without filesystem reads or absolute paths in the listing. Grouping happens after the unchanged-snapshot check; contracts, snapshot format, MCP discovery and prior messages are unchanged. When syncing, prefer equivalent upstream grouping and retain only the missing provenance fallback, not a second renderer.
- src/tools/code-mode/local-expansion.ts adds script, console-output and per-nested-call expansion choices. call-rendering.ts, result-rendering.ts and trace-rendering.ts wrap those regions without changing upstream preview budgets, configured keybinding hints, tool naming or Display defaults. Script highlighting retains upstream's per-row cache via a weak association with the mouse wrapper. Updates without a trace snapshot preserve choices; explicit snapshots prune absent calls. Completed nested results can collapse while the outer script streams. Nested view_image calls show title/path and errors only, leaving script-emitted images to Pi's outer renderer without conditional deduplication or model-content changes. delegation/tool-executor.ts retains image-call input/state but skips hidden raw results in the nested render cache. Ctrl+O remains host-owned and clears local choices on a global transition. Handlers retain only choices and the latest invalidate callback, never the host context or lastComponent. CARD-LICENSE.md preserves the local expansion provenance and MIT attribution.
- src/tools/code-mode/AGENTS.md records the old-context lifetime hazard: renderers must not retain the host render context or lastComponent, and patch cards must use the existing trace renderer.
- src/tools/view-image/tool.ts leaves result-content images to Pi. Its custom result renderer draws only the text-model fallback preview stored in details, reusing the shared image renderer and respecting showImages. Tool content and details are unchanged.
- Local runtime updates use a separate installation workspace. src/extension/session-lifecycle.ts no longer polls the npm registry on session startup; src/adapter/local-version-warning.ts is removed, with no compatibility branch or skip flag.
- Upstream's defaultActive:false tool registration replaces the former local runtime-admission and historical-declaration filters. Pi's recorded branch tool state remains authoritative on tree navigation.
- src/tools/apply-patch/tool.ts, src/tools/exec/command-tool.ts, src/tools/exec/write-stdin-tool.ts and src/tools/view-image/tool.ts also register inactive by default. Mode and extra-tool plans still explicitly enable them; tree navigation no longer automatically adds never-declared structured tools. Existing historical activations are unchanged.
- src/context-briefings.ts and src/adapter/notebook-status.ts discard context built for a run whose owner already aborted. Pi attributes hook failures to the registering extension, and an aborted run discards the context anyway; live-run failures still surface.
- src/extension/notes-migration.ts directs users to the Notes installation instructions instead of assuming an npm installation. Notes must be loaded, or the legacy continuity setting explicitly disabled, before old Notes-enabled configurations can run.
- src/adapter/activation, src/voice and src/ui/settings add the optional Codex Live gateway access described in [README.md](./README.md#voice-dictation-and-remote-access). src/voice/auth.ts distinguishes configured API keys from OAuth logins in authentication errors.
- src/voice/lan/settings-core.ts retains the boolean setting keys in the inferred public host-settings return type.
- package.json omits the upstream pi-browser dependency. LAN voice commands retain listener ensure/status and their receipts, without the browser-start adapter, connect subcommand or connect-only request state and receipt fields. The LAN voice page and manual browser startup remain available.
- src/tools/exec/command-tool.ts, src/tools/exec/write-stdin-tool.ts and src/tools/code-mode/notebook-rendering.ts give exported factories and renderers explicit public types. Released Pi 1.5.2 still exposes transitive TypeBox types in ToolDefinition; these annotations keep native-schema declaration emit portable without a direct TypeBox dependency.
- package.json uses a local static check without test execution, removes npm publish/prepack/prepare lifecycle scripts and publish metadata (including .npmignore), and ships UPSTREAM.md and CHANGELOG.local.md. The host-settings export has explicit types like the other public exports. Pi 1.5.2 and its native schema dependency now match upstream; the former local TypeBox pin is no longer needed. Build and native maintenance scripts remain.
- tests/context-briefings.test.ts and tests/notebook-status.test.ts are the retained local consequence tests for the aborted-run guards. Existing upstream tests are retained; the 5.0.0 sync changes no test files.
- README.md documents native Pi registration from a prepared installation workspace, local source loading and this repository's extension set, and clarifies QuickJS Code store lifetime and write-through behavior. Notes/history ownership remains with pi-notes-compaction rather than upstream's pi-agent-comms. References to unmigrated extensions and missing root API docs were removed.
- example custom-tool browser docs treat the CDP helpers in this package as canonical; there is no browser-cdp sync step. The retained command-backed example is opt-in and has no standalone browser extension dependency.
- scripts/build-changed-native-tool-binaries.mjs detects voice changes only under this package. scripts/verify-codex-tool-binaries.mjs has neutral bundled-binary messages.
- UPSTREAM_SYNC.md treats web search as an external extension and no longer points at the unmigrated pi-codex-web-run package. Its Pi 1.5.2 compatibility notes point to the current QuickJS Code runtime rather than the retired snapshot runtime.

Apart from the runtime differences listed above, functional sources, binaries, WASM and bundled profiles match the baseline.
