# pi-ui-kit sources and licenses

This private library carries the shared tool-card syntax and layout helpers adopted
from the workspace's own `pi-ui` and `pi-ask-user-question` modules. Original
copyright and license notices are preserved; this index does not relicense them.

| Source | Preserved record |
| --- | --- |
| claude-style-tools, copyright 2026 Serali-Nerri | `claude-style-tools-LICENSE` |
| pi-cc-extensions, copyright 2026 minuque: tool-card rendering helpers | `LICENSES/pi-cc-extensions.txt`, `claude-style-tools-THIRD_PARTY_NOTICES.md` |
| pi-Serraly `extensions/pi-ui` and `extensions/pi-ask-user-question` | this repository's own code, recorded in [UPSTREAM.md](../UPSTREAM.md) |

The library has no Pi resources and no private host API: it renders through the
public theme and component types only.
